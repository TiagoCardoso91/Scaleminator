# Layout checks

Screenshots of the page at different screen sizes, used to check the responsive layout.

- `scaleminator/`: `scaleminator.html` (fonts from Google Fonts)
- `with-fonts/`: `scaleminatorWithFonts.html` (fonts built in)

Each file name is `<width>x<height>_<view>.png`: `page` is the whole page, `drawer` has the controls drawer open, and `scale` has the scale menu open.
